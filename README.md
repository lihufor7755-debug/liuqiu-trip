# 小琉球四天三夜

2026/11/26 – 11/29，六個人的共編行程表。

打開網址就能改，不用登入、不用辦帳號。網址後面那串 24 碼就是這份行程的鑰匙。

## 這裡面有什麼

- **島嶼地圖**：在島上的日子，當天的點標在小琉球地圖上連成動線，
  直接告訴你「今天繞了島的哪半邊」。地圖是自己用 SVG 畫的。
- **連接段**：交通不是一張卡片，是掛在兩張卡片中間的一條細線。
  移動不是目的地。
- **分攤**：算出最少轉帳筆數，輸出「A 要給 B $740」。
- **離線可用**：訊號不好照樣能改，改動排在本機佇列，有訊號自動補送。

## 資料存哪

Supabase（一筆一列，後寫的勝出，刪除留墓碑）。
網頁本身是純靜態的，沒有伺服器要維護。

`設定.js` 裡那把 publishable key 本來就是設計成公開的。
真正擋住外人的是行程代碼：資料庫端只開放兩個函式，
不知道代碼的人一筆都撈不出來。

## 檔案

| 檔案 | 作用 |
|---|---|
| `index.html` | 入口 |
| `樣式.css` | 兩套主題，全走 CSS 變數 |
| `地圖.js` | 島形、地標、動線與航段帶 |
| `資料.js` | 行程骨架、合併與同步、分攤演算法 |
| `同步.js` | 跟後端收送 |
| `設定.js` | 後端連線設定 |
| `程式.js` | 畫面與互動 |
